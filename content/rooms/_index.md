title: "七个房间"
description: "欢迎来我家坐坐"
---
推开宅邸的门，你会看到七个房间。它们像家一样，各有各的用途，各有各的温度。


| 房间                         | 守护者                      | 你可以在这里……        |
| -------------------------- | ------------------------ | --------------- |
| [**风来**](/rooms/rhythm/)   | [路过](/root/lu-guo/)      | 听听外面的声音，留下你想说的话 |
| [**花开**](/rooms/radiance/) | [路上](/root/lu-shang/)    | 卸下疲惫，和自己待一会儿    |
| [**又生**](/rooms/risen/)    | [路明](/root/lu-ming/)     | 动手试试，把想法变成真的    |
| [**成蹊**](/rooms/roads/)    | [路炎晨](/root/lu-yanchen/) | 喝杯茶，聊聊你的作品      |
| [**若水**](/rooms/rivers/)   | [路宅](/root/lu-zhai/)     | 洗去尘埃，安放你的记忆     |
| [**不尽**](/rooms/roots/)    | [路痴](/root/lu-chi/)      | 翻翻书，发发呆，想些没用的   |
| [**道**](/rooms/reality/)   | [路标](/root/lu-biao/)     | 安静地坐一会儿，问问“为什么” |


每个房间都有一扇虚掩的门。你想先去哪儿？
