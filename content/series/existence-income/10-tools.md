**核心思想**：认知很重要，行动更重要。但如果没有工具，行动就容易变成空话。这一章，我们把全系列所有实用的工具、模板、清单汇总起来，形成一个“存在收入工具箱”。你可以随时取用，也可以根据自己的情况调整修改。

## 10.1 诊断工具

### 工具1：存在收入结构图

**用途**：可视化你的收入来源，看清自己的依赖程度。

**操作步骤**：
1. 统计过去一年的总收入（或最近12个月）。
2. 按六条路径分类，计算每条路径的占比：
   - 雇佣收入（工资、奖金、补贴）
   - 服务收入（咨询费、项目费、服务费）
   - 产品收入（销售收入、版权费）
   - 注意力收入（广告、打赏、带货）
   - 资本收入（投资收益、租金、分红）
   - 捐赠收入（赞助、供养）
3. 用饼图或柱状图画出结构。

**模板**：

```
我的存在收入结构图（20__年）

总金额：____元

- 雇佣收入：____元（占比__%）
- 服务收入：____元（占比__%）
- 产品收入：____元（占比__%）
- 注意力收入：____元（占比__%）
- 资本收入：____元（占比__%）
- 捐赠收入：____元（占比__%）

结论：
- 我有__条收入路径
- 最主要依赖的路径是：______
- 最需要发展的路径是：______
```

### 工具3：存在健康度自测表

**用途**：快速评估你的存在收入模式是否健康。

**操作步骤**：回答以下5个问题，每项1-5分（1=完全不符合，5=完全符合）。

1. 我的收入来源有2种以上，且不过度依赖某一条路。
2. 过去一年，我的存在资本（技能、作品、关系、信誉、符号）明显增长。
3. 如果离开现在的平台/公司，我依然有赚钱的能力。
4. 有人愿意无条件支持我（供养/赞助），是因为我这个人本身。
5. 我现在走的路，十年后依然能走得通。

**总分**：____分

- 20-25分：非常健康，继续保持。
- 15-19分：基本健康，但有风险点，需要关注。
- 10-14分：有较明显的风险，建议尽快调整。
- 5-9分：危险模式，急需改变。

## 10.2 路径选择工具

### 工具4：存在路径适配测试

**用途**：了解自己更适合走哪条路（或哪些路的组合）。

**操作步骤**：回答以下问题，在符合的选项打√（可多选）。

**第一部分：兴趣倾向**
- □ 我喜欢稳定的工作和可预期的收入 → 雇佣模式
- □ 我喜欢创造新东西，享受从0到1的过程 → 产品模式
- □ 我喜欢和人打交道，帮人解决问题 → 服务模式
- □ 我喜欢表达自己，享受被关注的感觉 → 注意力模式
- □ 我喜欢研究赚钱，对投资理财感兴趣 → 资本模式
- □ 我喜欢为某种理念或信仰付出 → 捐赠模式

**第二部分：能力优势**
- □ 我有很强的执行力和职业技能 → 雇佣模式
- □ 我有创作能力和用户洞察 → 产品模式
- □ 我有专业判断力和解决具体问题的能力 → 服务模式
- □ 我有表达欲、网感、持续输出能力 → 注意力模式
- □ 我有投资认知、风险承受力 → 资本模式
- □ 我有坚定的信念和精神感召力 → 捐赠模式

**第三部分：性格特质**
- □ 我喜欢规则清晰、按部就班 → 雇佣模式
- □ 我喜欢独立工作、自我驱动 → 产品/服务/注意力
- □ 我喜欢和人深度交流 → 服务模式
- □ 我喜欢公开表达、展现自己 → 注意力模式
- □ 我喜欢研究趋势、分析数据 → 资本模式
- □ 我喜欢奉献、有使命感 → 捐赠模式

**结果分析**：
- 看哪条路被勾选最多，那条路可能是你的“天赋路径”。
- 如果多条路得分相近，说明你适合走组合路。
- 没有哪条路是绝对适合，只是倾向性参考。

### 工具5：存在价值排序表（决策工具）

**用途**：当两条路冲突时，帮你基于自己的价值观做出选择。

**操作步骤**（详见8.3节）：
1. 列出你的核心需求（安全、自由、意义、认同、财富、成长、关系、健康等）。
2. 给每个需求分配权重（1-5，越重视越高）。
3. 为每条备选路径满足每个需求的程度打分（1-10）。
4. 计算加权总分，比较。

## 10.3 组合配置工具

### 工具6：存在组合配置器

**用途**：帮助你分配精力到不同路径上，实现平衡发展。

**操作步骤**：
1. 确定你当前的人生阶段（起步期/成长期/成熟期/自由期）。
2. 参考以下建议配置，结合自身情况调整。
3. 按百分比分配你的精力/时间到四个层次。

**参考配置表**：

| 人生阶段 | 稳定层 | 增长层 | 未来层 | 意义层 |
|---------|--------|--------|--------|--------|
| 起步期（20-30岁） | 60-70% | 20-30% | 5-10% | 5-10% |
| 成长期（30-40岁） | 40-50% | 30-40% | 10-15% | 5-10% |
| 成熟期（40-50岁） | 20-30% | 30-40% | 20-30% | 10-20% |
| 自由期（50岁以后） | 0-20% | 20-30% | 30-40% | 30-50% |

**我的配置**：

| 层次 | 路径 | 精力分配 % |
|------|------|------------|
| 稳定层 | 雇佣/基础服务 | |
| 增长层 | 产品/注意力 | |
| 未来层 | 资本 | |
| 意义层 | 捐赠/无偿热爱 | |

**备注**：每季度可调整一次。

### 工具7：存在资本积累清单（每日/每周/每月/每年）

**用途**：把抽象的资本积累变成可执行的日常习惯。

**每日清单**（选做1-2项）：
- [ ] 今天学到了一个新东西（技能资本）
- [ ] 今天做了一件可以留下记录的事（作品资本）
- [ ] 今天认识了一个新朋友/给一个老友发了消息（关系资本）
- [ ] 今天兑现了一个小承诺（信誉资本）
- [ ] 今天花5分钟想了想“我是谁”（符号资本）

**每周清单**：
- [ ] 本周完成了一个小产出（文章/代码/设计/复盘）
- [ ] 本周和一个行业外的朋友交流
- [ ] 本周主动帮助了一个人
- [ ] 本周记录了自己的一个“高光时刻”或“至暗时刻”
- [ ] 本周学习了2小时投资/理财知识

**每月清单**：
- [ ] 本月完成了一个可展示的作品
- [ ] 本月参加了一次线下/线上社交活动
- [ ] 本月请一位前辈/贵人吃了饭或通了话
- [ ] 本月做了一次月度复盘
- [ ] 本月定投了一笔钱（哪怕很少）

**每年清单**：
- [ ] 本年完成了一个代表作
- [ ] 本年新增了5个“愿意为我背书”的人
- [ ] 本年写了一封给自己的信
- [ ] 本年做了一次全面的存在资本盘点
- [ ] 本年向一个公益/开源项目捐了款或时间

## 10.5 进阶工具

### 工具10：存在传承计划表

**用途**：思考并规划你希望留下的东西（适合40岁以上或想得更远的人）。

**模板**：

```
我的存在传承计划

一、我想留下什么？
- 血脉传承：子女、后代
- 作品传承：著作、作品集、代码库
- 思想传承：价值观、方法论、经验总结
- 资本传承：财富、资产、股权
- 符号传承：名字、品牌、精神

二、传承给谁？
- 直系后代
- 学生/弟子/徒弟
- 社会公众
- 某个组织/基金会

三、如何准备？
- 需要整理什么材料？
- 需要建立什么机制？
- 需要培养什么人？
- 需要在什么时间点完成？

四、障碍与应对
- 可能遇到什么困难？
- 怎么解决？

五、开始时间
- 我打算从______开始行动。
- 第一步：______
```

### 工具11：存在自由刻度表

**用途**：衡量你离“存在的自由”还有多远。

**操作步骤**：给自己打分（1-10分），并记录原因。

1. **财务自由**：被动收入覆盖基本生活所需？ ____分
2. **时间自由**：能自主支配大部分时间？ ____分
3. **空间自由**：可以在任何地方生活/工作？ ____分
4. **关系自由**：可以自由选择与谁交往？ ____分
5. **意义自由**：正在做自己真正热爱的事？ ____分
6. **存在自由**：即使没有人买单，也觉得自己有价值？ ____分

**总分**：____分

**记录**：每项为什么是这个分数？接下来一年想提升哪一项？
